# SpaceX Dogecoin Minning

A modern digital banking UI/UX demo. This is a front-end prototype only: it is not a real bank, does not connect to real accounts, and does not move money.

## Run locally

**Prerequisites:** Node.js (LTS recommended).

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local URL printed by Vite (usually `http://localhost:3000`).

## Production build

```bash
npm run build
```

The production files are generated in `dist/`. Preview them locally with:

```bash
npm run preview
```

## Deploy to Vercel

- Framework preset: **Vite**
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`
- Root directory: project root

No environment variables are currently required for this front-end demo.

## Demo limitations

Login, signup, transfers, cards, balances, and transactions are illustrative UI/demo features. Do not enter real banking credentials or sensitive financial information.
